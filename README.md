# Needle DAW

[**Needle**](https://github.com/bencariaga/needle-daw) is a digital audio workstation (DAW) built with React and Tauri, written in TypeScript and Rust programming languages. It has the visual simplicity of an audio editor with the featural sophistication of a DAW.

## Etymology

It is an indirect reference to the word "muse". Filipino word "paraluman" means "muse", but also means "compass" or "needle of the compass". Therefore, the word "needle" has been chosen for the app's name.
